A Worked Example of Volatility Scaling

20 November 2023

Fixture notice: this page is for automated tests only and is not investment material.

How to size a position so that its expected swings stay roughly constant, step by step.

The rule

The idea fits in one line: hold less of an asset when it is jumpy and more when it is calm. With a target volatility \(\sigma^*\) and an estimate \(\hat\sigma_t\), the weight is

wt=σ*σ^t

The weight goes as the estimate goes up, so w and σ move in opposite directions.

We cap the weight at two so that a quiet spell cannot lever the book without limit.

Steps

  1. Estimate recent volatility, for example with an exponentially weighted window.
    • Shorter windows react faster.
    • Longer windows are steadier.
  2. Divide the target by the estimate.
  3. Apply the cap.

A rule you can state in one sentence is a rule you can test.

In code the whole thing is short:

def weight(target, est, cap=2.0):
    return min(target / est, cap)

Figure 1. The weight falls as estimated volatility rises.

Scaling does not make returns better on its own. What it does is make one month look more like the next, which makes every other decision easier to judge.
