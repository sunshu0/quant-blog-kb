“Quiet Quarters”? A sample blog post

Listen to this blog

This sample post is written for the test suite only.

A calm opening

Imagine a market that drifts sideways for a whole quarter. A reader might ask whether the quiet means anything at all, or whether it is simply what most quarters look like when nobody is watching.

 

  • Quiet quarters are common in the made-up series used here.
  • Loud quarters cluster together, which is the point of this toy example.
Chart 1: Toy distribution of quarterly ranges

Simulated ranges from an invented random walk; nothing here is real data.

Source: test fixture

The second half of the argument is that a quiet quarter tells you little about the next one1 . We repeat the toy experiment many times and the answer does not change, which is reassuring for a fixture and boring for a reader.

Finally, we note that any pattern found by searching many windows needs a correction for the number of windows searched. Otherwise the best window always looks impressive.

 

1 A footnote written for the fixture: it explains nothing in particular.
