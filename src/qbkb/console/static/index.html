qbkb 量化博客中文知识库
演示模式：使用自带的示例文章，不联网、不需要 API key。示例文章是为演示自己写的，不是真实文章。 在「设置」里填好 DeepL 的 key 后会切到真实模式。
原文链接

从左边选一篇文章。

栏目抽样

抽样表就是 output\sections\<站点>.csv，在这里标和用 Excel 标是同一份。 每个栏目抽约 20 篇（不超过 30 篇的栏目列全部）。标「要 / 不要」后实时算占比：高于 80% 整栏采集、 60%–80% 补抽或问老板、低于 60% 不够。「翻译这一栏」只翻抽中文章的标题和摘要，翻过的会缓存、不重复计费。

运行一次更新

发现新文章 → 抓取 → 抽取正文、判定栏目 → 翻译（只翻选定的栏目） → 导出 Markdown。 已经处理过的文章不会重复花额度；中途停下，下次运行会从中断处接着跑。
